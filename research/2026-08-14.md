# Research snapshot — 2026-08-14

This dated file is evidence of the design baseline only. The skill must **not** treat these versions as permanently current; it re-resolves package state at execution time.

## OpenAI plugin packaging

Verified from OpenAI Developers on 2026-08-14:

- A plugin requires `.codex-plugin/plugin.json`.
- A plugin can consist of a skill without an MCP server when packaged instructions/resources are sufficient.
- Skills live below `skills/<skill-name>/SKILL.md` and may include references and scripts.
- Repo/personal marketplaces use `.agents/plugins/marketplace.json`; plugin paths must be relative and `./`-prefixed.

## Compatibility/standards facts used in the design

- React Three Fiber's official installation docs require matching the Fiber major to the React major (Fiber 8 with React 18; Fiber 9 with React 19 at the time of this snapshot).
- WebGPU remained limited-availability on MDN and secure-context-only; it must be feature-detected rather than assumed.
- W3C WebXR remained an actively evolving standards-track API; current W3C semantics must be checked rather than using proposal-era snippets.
- Khronos lists glTF 2.0 as the current glTF specification family, with 2.0.1 as the current spec patch.
- Rapier's JavaScript package is WebAssembly and initializes asynchronously; official docs provide `-compat` packages for runtimes/bundlers that cannot handle normal WASM loading.
- Cesium's official npm setup requires its static runtime assets and a correctly configured `CESIUM_BASE_URL` when using the documented manual bundler path.
